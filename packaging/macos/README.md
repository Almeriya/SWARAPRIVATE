# SWARA XT 1.3.1 macOS — Universal QA candidate

This is **not a public release**. Packages are produced from the single
immutable, provenance-checked CI universal candidate, ad-hoc signed for QA only,
without Developer ID signing or notarization. Mac audio-reference authority
remains pending independent approval.

## Assets

- `SwaraXT-macOS-Universal-v1.3.1.zip`: AU and VST3 bundles, skin examples,
  decorations, GPL license, font/artwork licenses, copyright, source notice.
- `SwaraXT-macOS-Universal-v1.3.1.pkg`: system-wide AU/VST3 installation.
- `SwaraXT-macOS-Universal-v1.3.1-corresponding-source.tar.gz`: exact SW2
  source SHA, pinned Shruthi/avrlib source and JUCE 9.0.1 source (verify contents).
- `SHA256SUMS` and `package-qa-manifest.json`: SHA-256 package inventory.

Manual ZIP bundle layout: `Swara XT 1.3.1 macOS/AU/Swara XT.component`,
`VST3/Swara XT.vst3`, `Skin Examples/`, `Documentation/`.

The PKG installs to `/Library/Audio/Plug-Ins/Components/Swara XT.component`
and `/Library/Audio/Plug-Ins/VST3/Swara XT.vst3`. It has no post-install
scripts. Installation requires administrator authorization through macOS.

The manual ZIP is for users who prefer to install the whole AU/VST3 bundle
themselves, preserving its contents and signature. macOS 11.0 or newer is
the deployment target; actual host compatibility needs native testing.

## Qualification and package generation

The pre-existing `.github/workflows/macos-qualification.yml` universal-build
stage compiles one arm64/x86_64 candidate, checks both bundles and ad-hoc
seals, writes `unsigned-universal/provenance.json` and its SHA-256 inventory.

`scripts/macos/package_release_candidate.py` consumes **only that exact
candidate**. Inputs are the source checkout, pinned JUCE checkout, candidate
bundle directory, candidate full commit SHA, version 1.3.1, and a new output
directory. It refuses mismatched provenance, missing bundles, altered files,
incorrect identities or architecture slices, invalid signatures or dirty
source trees. The ZIP/PKG are roundtrip inspected and checksummed. CI never
touches already installed user plugins.

No signing secrets are used or required. The QA packages are not approved for
public distribution. Native audio-reference authority, full CTest and AU/VST3
host validation, and independent review remain mandatory.

## Corresponding source

The QA source archive includes the exact repository revision and initialized
pinned submodules as well as pinned JUCE source. It does not use GitHub's
submodule-incomplete autogenerated source ZIP. See `packaging/SOURCE.txt`
for dependency provenance, license notices and source distribution obligations.
